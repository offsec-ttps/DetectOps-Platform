# Getting Started

Everything you need to install, configure, and understand the platform before diving into a specific dashboard section.

## The 3-step quickstart

1. Check [Prerequisites](prerequisites.md).
2. Run [Installation](installation.md) → app at `http://localhost:3000`.
3. Open the [Deploy Hub](../labs/deploy-hub.md) and stand up your first lab.
