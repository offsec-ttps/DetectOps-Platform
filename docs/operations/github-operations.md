# GitHub Operations

**Sidebar section:** GitHub Operations

Detection-as-code workflows that connect the platform to your detection repositories. Requires `GITHUB_TOKEN` (and the `gh` CLI for some flows).

## In this section

| Subsection | Route | What it does |
|-----------|-------|--------------|
| [PR Management](pr-management.md) | `/pr-management` | List and filter detection-repo pull requests. |
| [Agentic Sync](agentic-sync.md) | `/agentic-sync` | Automated repo/detection synchronization. |
| [CI/CD](cicd.md) | `/cicd` | Pipeline & integration status for detection-as-code. |

Rules authored in the [Rule Workspace](../engineering/rule-workspace.md), [Detection Packs](../detection/detection-packs.md), and [Reports](reporting.md) can all be pushed to GitHub through these flows.
