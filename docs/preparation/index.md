# Preparation

**Sidebar section:** Preparation

The Preparation section is where you stand up the environments and modules you'll run simulations against. It maps to the dashboard's **Preparation** menu.

## In this section

| Subsection | Route | What it does |
|-----------|-------|--------------|
| [Deploy](../labs/deploy-hub.md) | `/deploy` | Stand up a lab or fleet — Local, Cloud, or Remote Fleet. |
| [Attack Simulations](../simulation/attack-simulations.md) | `/simulations` | Category grid of simulation modules (LOTL, Phishing, Ransomware) + Atomics Execution. |
| [Module Marketplace](../system/module-marketplace.md) | `/marketplace` | Build, validate, sign, install, and approve simulation modules. |
| [Detection Lab (advanced)](detection-lab.md) | `/detection-lab` | Power-user lab console: blueprints, templates, VM control, validation. |

## Deploy paths

The Deploy hub offers three environments — see each guide:

- [Local Lab](../labs/local-lab.md) — VirtualBox/Vagrant VMs on this host.
- [Cloud Lab](../labs/cloud-lab.md) — SAR/GOAD in your AWS/Azure/GCP account.
- [Fleet Server](../labs/fleet-server.md) — a signed agent on your own endpoints.

To tear anything down, see [Manage Labs](../labs/manage-labs.md).
