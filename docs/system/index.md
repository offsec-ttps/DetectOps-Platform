# System

**Sidebar section:** System

Platform administration: the MCP server, integrations, in-app docs, and settings (LLM providers, outbound MCP servers, cloud credentials). Maps to the dashboard's **System** menu.

## In this section

| Subsection | Route | What it does |
|-----------|-------|--------------|
| [MCP Registry](mcp-server.md) | `/mcp-registry` | Manage the platform's own MCP server: mint/revoke API keys, view stats. |
| [Integrations](integrations.md) | `/integrations` | Connect external systems (SIEMs, ticketing) with testing + SSO. |
| [Documentation](documentation.md) | `/docs` | In-app generated documentation. |
| [Settings](settings.md) | `/settings` | Administration + cloud credentials. |
| [LLM Providers](llm-providers.md) | `/settings/llm-providers` | Configure the LLM providers that power AI features. |
| [MCP Servers](mcp-servers.md) | `/settings/mcp-servers` | Register outbound MCP servers used for enrichment. |
